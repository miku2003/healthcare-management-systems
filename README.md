# 🏥 Healthcare Management System

A modern web application for managing patient appointments and admin scheduling, built with **Next.js**, **TypeScript**, **Tailwind CSS**, and **Appwrite**.

## 🔧 Features

- Patient registration and login  
- Book and manage doctor appointments  
- Admin panel to confirm, reschedule, or cancel appointments  
- SMS notifications using Twilio  
- File upload and storage via Appwrite  
- Fully responsive UI  

## 🚀 Getting Started

1. Clone the repo  
   `git clone https://github.com/miku2003/healthcare-management-systems.git`

2. Install dependencies  
   `npm install`

3. Add your `.env.local` file with Appwrite & Twilio configs

4. Start the app  
   `npm run dev`
